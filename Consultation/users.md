## 1. Таблица пользователей (Акторы системы)

В системе выделены основные и вторичные акторы. Основные акторы напрямую взаимодействуют с интерфейсом системы. Вторичные — это внешние системы, которые обмениваются данными с платформой по API или протоколам связи.

| Роль (Актор) | Тип | Описание роли | Основные возможности (Прецеденты) |
| :--- | :--- | :--- | :--- |
| **Сотрудник** | Основной | Рядовой работник компании, которому направлен опрос. | Переход по уникальной пригласительной ссылке, заполнение формы, сохранение ответов. |
| **Руководитель подразделения** | Основной | Линейный менеджер, оценивающий команду и контролирующий прохождение опросов. | Просмотр результатов опросов **только своих прямых и косвенных подчиненных**, экспорт отчетов по своей команде. |
| **HR-специалист** | Основной | Сотрудник отдела кадров, администрирующий систему опросов. | Создание опросов, управление шаблонами, импорт сотрудников из Excel, настройка правил автосоздания, просмотр результатов всех опросов, выгрузка отчетов, удаление данных. |
| **Внешняя HR-система (1С / HRM)** | Вторичный | Корпоративная система учета кадров. | Отправка Webhook-событий (например, «Аттестация пройдена») для запуска автосоздания опросов. |
| **Почтовый сервер (SMTP)** | Вторичный | Внешний сервис рассылки корпоративной почты. | Отправка email-приглашений и ссылок на опросы сотрудникам. |

## 2. Список прецедентов (Use Cases)

На основе таблицы пользователей и функциональных требований (FR) выделены следующие ключевые прецеденты (варианты использования):

### Прецеденты роли «Сотрудник»
*   **UC-01. Пройти опрос.** Пользователь переходит по уникальной ссылке из письма, заполняет форму и сохраняет ответы. Система валидирует токен и проверяет, не истек ли срок прохождения.

### Прецеденты роли «Руководитель»
*   **UC-02. Просмотреть результаты подчиненных.** Руководитель видит агрегированные данные только по тем сотрудникам, которые находятся в его ветке иерархии (согласно RBAC).
*   **UC-03. Экспортировать отчет по команде.** Формирование файла DOCX/PDF с результатами опросов подчиненных сотрудников.

### Прецеденты роли «HR-специалист»
*   **UC-04. Создать/отредактировать опрос.** Задание темы, сроков и выбор шаблона для нового опроса.
*   **UC-05. Управлять шаблонами опросов.** Создание, редактирование и удаление шаблонов вопросов в визуальном конструкторе.
*   **UC-06. Импортировать иерархию из Excel.** Загрузка файла с оргструктурой (подразделения, сотрудники, руководители) с валидацией и обновлением связей.
*   **UC-07. Настроить правила автосоздания.** Создание правил (триггеров), по которым система будет автоматически генерировать опросы (например, «Новичок», «Аттестация»).
*   **UC-08. Просмотреть результаты всех опросов.** Просмотр аналитики и ответов по всей компании с возможностью фильтрации.
*   **UC-09. Экспортировать отчет с удалением.** Скачивание результатов опроса в электронном виде с последующим безвозвратным удалением данных из базы (152-ФЗ).
*   **UC-10. Удалить опрос.** Ручное удаление опроса или настройка автоудаления по таймеру (через N дней).

### Системные прецеденты (Автоматические)
*   **UC-11. Обработать Webhook от HR-системы.** Система принимает внешний сигнал о кадровом событии, проверяет правила и инициирует создание опроса.
*   **UC-12. Отправить email-уведомление.** Автоматическая рассылка приглашений и напоминаний через SMTP-сервер на основе очереди задач.
